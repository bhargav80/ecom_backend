# E-commerce Backend

Node.js + Express backend for an e-commerce app with MongoDB.

## Features

- Auth and admin management
- Product and review APIs
- Cart and order handling
- Vendor routes
- Cashfree payment integration
- Cloudinary image upload support



## Main API Groups

- `/api/auth`
- `/api/products`
- `/api/reviews`
- `/api/cart`
- `/api/orders`
- `/api/paymentRoutes`
- `/api/vendor`
- `/api/admin`
